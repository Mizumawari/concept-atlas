# 蓄積された約400本の身体・意識・認知の探究記録を「3D星図」にした――『Notebook 概念アトラス』を作りました

これまでnoteや手元の研究ノートに、身体感覚、短眠、自律神経、DMN/RAS、PNSE（持続的非象徴的体験）、深層筋膜、そして音楽やAIにいたるまで、膨大な自己観察と考察を書き溜めてきました。

気づけばその記録は**400本近く**に達しています。

しかし、記事が増えれば増えるほど、ひとつの大きな壁にぶつかるようになりました。
**「ブログのタイムライン（時系列リスト）という構造では、思考の全体像がまるで見えなくなる」**ということです。

私の探究において、「短眠と血・神バランス」は「深層筋の収束と拡散」と繋がっており、それは「あくびと脳脊髄液（CSF）」や「DMNの再帰停止（PNSE）」、さらには「Sunoでの音響設計」とも地続きのひとつのシステムとして動いています。
それなのに、普通のWebサイトだと「昨日の記事」と「以前の土台となった記事」がバラバラに引き裂かれてしまう。

そこで、蓄積されたすべての資料、概念、YouTube解説、note記事をひとつの立体的な空間に統合し、自由に歩き回れる**3DインタラクティブWebアプリ『Notebook 概念アトラス』**を構築しました。

今回は、この「アトラス（概念の星図）」がどんなもので、どう遊べるのかを紹介します。

---

## 1. 『概念アトラス』とは何か？

一言で言えば、**「約400本の考察ドキュメントと70以上のコア概念を、3D空間にマッピングした思考の天球儀（計器）」**です。

画面を開くと、深海あるいは宇宙のような濃紺の空間の中に、色とりどりの光のノード（星々）が浮かび上がります。

```
       [ 身体・生理 ] ── (深層筋・スポンジモデル)
             │                     │
      (血と神のバランス)           │
             │                     │
       [ 睡眠・覚醒 ] ────── (あくび・CSF循環)
             │                     │
       (基底覚醒 / 静寂)           │
             │                     │
       [ 意識・自己感覚 ] ── (DMN再帰停止 / PNSE)
```

単なるお飾り用の3Dグラフィックではありません。
すべてのノードは実際のテキストデータを統計的・概念的に解析して配置されており、**「意味が近い記事同士」「共通の概念を含む考察同士」が引力で引き合い、有機的な星座を形作っています。**

## 2. 8つの領域と、張り巡らされた70の概念

アトラスの中では、すべての記録が**8つのドメイン（顔料カラー）**に分類されています。

1.  **身体・生理（コーラルオレンジ）：**
    深層筋・筋膜、毛細血管スポンジモデル、収束と拡散、呼吸、自律神経、周天、内部の熱、温冷刺激（サウナ・ヴィムホフ）
2.  **睡眠・覚醒（スレートブルー）：**
    短眠・ショートスリープ、睡眠圧、あくび、カフェインとアデノシン、血と神、疲労と身体回復
3.  **認知・脳・予測（ミントグリーン）：**
    DMN（デフォルト・モード・ネットワーク）、RAS（網様体賦活系）、予測誤差、反芻ループ、ゲイン・ノイズ、神経可塑性
4.  **意識・自己感覚（ラベンダーパープル）：**
    PNSE、俺フィルター、自己物語、悟り・独覚、瞑想・静寂基底、現実感（リアリティの質感）
5.  **心理・感情（ウォームアンバー）：**
    不安、情動、欲求、快不快、ストレスと防衛反応
6.  **社会・人生・思想（セージグリーン）：**
    他者と社会性、倫理、AI、価値の非対称性、永井均と清水俊史（野生の哲学と仏教学）、真理と現れの枠組み
7.  **実践・方法（サンドベージュ）：**
    行動開始・着手、地味な初期投資と習慣化、身体操作のチューニング、書籍化プロジェクト
8.  **音楽・創作（ソフトローズ）：**
    音響構造、Suno AIプロンプトエンジニアリング、Neural Mantra、リズムと身体同期

これらの星々をクリックすると、その概念がどの記事でどのように使われ、どの別の概念へと発展していったのかが、光のリンクで瞬時に可視化されます。

## 3. このアトラスでできること

単に眺めるだけでなく、実用的なリサーチ・読書ツールとして以下の機能を詰め込みました。

### ① 3つの視点で空間を切り替える（レイアウト機能）
*   **「概念網（net）」：** 概念の共起と意味の近さによって自然に引き合う、もっとも有機的な銀河マップ。
*   **「SRC順（spiral）」：** 蓄積された思索の軌跡を、螺旋状のタイムラインとして眺める時間軸マップ。
*   **「分類別（cat）」：** テーマごとに整然と島（アイランド）に分かれたコロニーマップ。

### ② 全文・概念・タイトルのリアルタイム検索
上部の検索バーに「あくび」「カフェイン」「スポンジ」「PNSE」など気になる単語を入れると、該当する星々だけがクローズアップされ、関連のない星がスッと暗転します。膨大なアーカイブから目的の文脈を瞬時にあぶり出せます。

### ③ ガラス調の詳細パネル（その場で読める・観られる）
星をクリックすると、右側からすりガラスのようなパネルが静かにスライドインします。
*   記事のタイトル、公開日、要約
*   使われているコア概念タグ
*   関連する資料へのジャンプリンク
*   **note記事への直接リンク**
*   **YouTube音声解説・動画のインラインプレイヤー**（その場で再生可能）
*   さらには**本文そのものもパネル内で直接読破可能**

### ④ 「一覧ビュー」と「概念索引ビュー」
「3Dを動かすより、一覧表でざっと見たい」というときのために、画面上部のタブから**「一覧（テーブル表示）」**と**「概念索引（ディクショナリ表示）」**にワンタップで切り替えられます。

## 4. なぜ「地図」が必要だったのか

私にとって、この身体観察や認知の探究は、バラバラの思いつきの集まりではありません。

「身体の余計な力みを抜く（引き算の最適化）」という実践が、やがて「思考のノイズの沈静化（DMNの鎮静）」を呼び、それが「持続的な静寂の覚醒（PNSE）」へと接続し、さらに「睡眠要求の変容（短眠・血と神）」や「環境適応（寒冷・体温維持）」へと波及していく。

すべてはひとつの**「人間という生体の低摩擦運用」**をめぐる連鎖です。

しかし、それを文章で一本ずつ書いていくと、読んでいる人（そして自分自身ですら）「今、森のどのあたりを歩いているのか」を見失ってしまいます。

このアトラスは、いわば**「Mizumawariという人間が、自らの身体と意識の内奥を徹底してフィールドワークし描き上げた全測量図」**です。

## 5. お勧めの歩き方ガイド（テーマ別ラインナップ）

このアトラスには、決まった一本道の読み順はありません。どこから入っても必ず別の星へと繋がっていきます。
「どこから見ればいいかわからない」という方のために、代表的な**5つの散歩ルート（ラインナップ）**を用意しました。検索バーにキーワードを入れて辿ってみてください。

---

### ルート1：【深層脱力・スポンジ身体論】ルート
> **「力を抜くとは、重力と血管の物理現象である」**
*   **入口キーワード：** `スポンジ` / `深層筋` / `収束と拡散` / `脱力`
*   **おすすめの歩き方：**
    1. 「毛細血管スポンジモデル」からスタート
    2. 表面の筋肉ではなく「骨格と深層筋の引き算」へ
    3. 「呼吸・自律神経」を経て、身体前面・後面のテンション構造へ
*   **こんな人におすすめ：** 慢性的な肩こりや緊張が抜けない人、武術・身体操作の内部感覚に興味がある人。

---

### ルート2：【短眠・覚醒・血と神の物理】ルート
> **「睡眠は気合いではなく、循環と熱と脳脊髄液の収支決算」**
*   **入口キーワード：** `短眠` / `血と神` / `あくび` / `カフェイン`
*   **おすすめの歩き方：**
    1. 「短眠」の基本記録から「血と神のバランス論」へ
    2. なぜ「あくび」で脳脊髄液（CSF）が巡り、睡眠圧が抜けるのか
    3. 最新の「カフェインが効かない理由・基底覚醒とスーン」の星へ接続
*   **こんな人におすすめ：** 睡眠の質を根本から見直したい人、日中の眠気や疲労感のメカニズムを解剖したい人。

---

### ルート3：【脳の静寂・DMN鎮静・PNSE】ルート
> **「脳内の独り言（物語）が止まったとき、世界はどう見えるか」**
*   **入口キーワード：** `DMN` / `反芻` / `PNSE` / `静寂`
*   **おすすめの歩き方：**
    1. デフォルト・モード・ネットワーク（DMN）の暴走と「俺フィルター」へ
