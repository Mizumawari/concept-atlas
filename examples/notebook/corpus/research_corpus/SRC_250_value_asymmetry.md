# 価値は「何を得るか」だけでは決まらない
## ──現在の状態と「この世の全て」を交換する思考実験

### 0. この思考実験の目的
もし現在の状態になる「以前」の自分に戻ることを条件として、「無限の金」と「自分自身を直接操作する能力を除き、この世の全てを自由自在に操作できる能力」を与えられるとしたら、それでも現在の状態を手放したいと思うのか。
重要なのは、「無限の金や万能な能力に魅力がない」と主張することではない。それらは非常に魅力的であるが、それでも「現在の状態を失うこと」と引き換えなら欲しくない。この違いを考える。

# 1. AとBという二つの状態
## A：現在の状態
外部刺激がなくても欠乏を感じる必要がなく、「何かが足りないから、それを埋めなければならない」という構造が弱い状態。「何も得られない」のではなく、「何かを得続けなくても成立する」という状態である。
## B：以前の状態＋無限の金＋外界の完全操作能力
現在の状態になる以前の自分に戻り、世界を自由に変えられるが、それを「面白い」と感じる側の自分までは万能ではない状態。

# 2. Bには本当に強烈な魅力がある
Bはめちゃくちゃ面白い。しかし、Aを失ってまで欲しいわけではないというのが核心である。

# 3. 「追加」と「交換」は全く違う
Aを維持したままBを追加できるなら欲しい。しかし「Aを失う代わりにBを得る（B - A）」となると、必ずしもプラスにはならない。「Aを失うコストが、Bの魅力を上回る」という意味である。

# 4. 「無限の金」でも問題は解決しない
無限の金は外部世界にある欠乏を解消するが、「何かを得なければ満たされない」という構造そのものを消すわけではない。外界を無限に拡張することと、外界への依存をなくすことは別問題である。

# 5. 「無限」と「無限に欲しくなる」は違う
「刺激を無限に追加できる」ことが、必ずしも「無限に価値が増える」ことを意味しない。刺激を必要としないこともまた価値である。

# 6. 自由には二種類ある
* 外界を支配する自由（Bの自由）：世界を自分の望む通りに変えられる自由。
* 外界に依存しない自由（A側の自由）：世界が自分の望む通りにならなくても、それだけで自分が欠ける必要がない自由。

# 7. 「今がしんどい人」にとってはBしか見えない
現在がしんどい人にとっては、Bは現在からの脱出手段であり、Bを選ぶのは当然である。その人にとって「何も求めない」は「欲しいものを諦める」という意味に見えてしまう可能性がある。

# 8. 欠乏している状態では、欠乏のない状態の価値を評価しにくい
「何も得られない（欠乏）」と、「何かを得続ける必要がない（欠乏への依存が薄い）」は全く違うが、この違いは体験によって初めて比較可能になる。

# 9. ただし「自己を愛する人」も同じ思考実験に入る
「苦しみも含めて自分の人生だ」と自己を肯定している人も、「現在の自分を失いたくない」という理由でBを拒否し得る。

# 10. 三つの価値構造
* 第一段階（欠乏から逃れたい）：Bが圧倒的に魅力的。
* 第二段階（自己と人生そのものを肯定している）：現在の自分を失うこと自体が損失のためAを選ぶ。
* 第三段階（欠乏そのものへの依存が薄い）：Bは普通に面白そうだが、現在を失う理由がないためAを選ぶ。「楽しいものがない」ことと「楽しいものを必要としない」ことは違う。

# 11. 同じ結論でも、理由は全く違う
第二段階は「自己を失いたくない」から、第三段階は「失う理由がない」から現在を選ぶ。「現在を守りたい」と「現在を失う理由がない」は違う。

# 12. 「現在の状態には、この世の全て以上の価値がある」という表現の正確な意味
客観的な価値ランキングではなく、「自分にとって、現在の状態を失わずにいることの価値は、Bを得る価値を上回る」という本人の選好に基づく価値判断である。

# 13. 「世界の全て」と「現在の状態」は、同じ尺度で測れない
「世界を自由自在に操作できること」と、「世界から何かを得なければ成立しないという必要性が薄いこと」は、別の価値軸にある。

# 14. 価値は「追加」だけでなく「依存の減少」にも存在する
幸福のモデルには「追加」だけでなく、「欲求や刺激、環境への依存が減る」「何かを追加しなくても成立する範囲が広がる」という方向の価値も存在する。

# 15. 「苦しみがない」と「苦しみを必要としない」は違う
「苦しみがないから価値がある」わけでもなく、「苦しみをどう評価するか」に強く自己価値を依存しなくなる方向があり得る。

# 16. 「自己があること」と「自己を必要とすること」も違う
「自己の存在を自分の価値の必須条件としているか」という違いである。

# 17. この思考実験が示すもの
人間が何を価値あるものとして感じるかは、その人がどのような状態から世界を経験しているかによって変わる。

# 18. 価値判断の非対称性
Aを経験した人はBの魅力を理解できるが、Bしか経験していない人がAの価値（何かを必要としなくても成立していること）を理解するのは難しい場合がある。

# 19. だから、これは「幸福の優劣」ではなく「価値関数の違い」の問題
どちらが正しいかを決める必要はない。重要なのは「本人が何を失いたくないと感じるのか」であり、価値は外から与えられる物量だけでは決まらない。

# 20. 最終的な核心
「世界の全てを手に入れられるとしても、それを得るために現在を失う理由がない」という選択が成立する。
「何を持っているか」ではなく、「何を持たなくても成立できるか」もまた、価値になり得る。
価値の基準そのものが変化し得る、という話である。
