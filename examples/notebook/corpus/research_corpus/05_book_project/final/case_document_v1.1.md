# 本冊子の目的
本冊子は、一人称による長期的な観察記録を、FACT / USER MODEL / PATTERN / UNRESOLVEDの4層に分けて整理したケース・ドキュメントである。
本冊子は、単一の原因や理論によって体験を説明することを目的としない。
「観察された記述」「本人による解釈」「資料間のパターン」「未解決事項」を分離して保存する。

# 用語上の注意
【用語上の注意】
本冊子に登場するDMN、RAS、予測処理等の神経科学的用語と、俺フィルター、自己パッケージ等の独自概念は、同一の認識論的地位を持たない。
本人が神経科学的用語を用いて自身の体験を説明している場合、それは原則として「本人が事象を説明するために採用したモデル（USER MODEL）」として扱う。
それらの記述は、実際の神経活動が測定・確認されたことを意味しない。

# この冊子の読み方
読者は以下の4層を区別して読む必要がある。
* **[SOURCE FACT]**: 資料に記録された事実・本人の報告。
* **[USER MODEL]**: 本人が体験を説明するために使用したモデル・比喩・仮説。
* **[CROSS-SOURCE PATTERN]**: 複数資料を比較した際に確認できる共起、前後関係、対照性、非対称性。
* **[UNRESOLVED]**: 資料から判断できない事項、または記述が不足している事項。

# Part I: この探究は何を追ってきたのか

**[SOURCE FACT]**
本コーパスの初期記録群において、観察対象は「特定の問題解決」から「主観的体験の微細なモニタリング」へと推移していく過程が記録されている。
しかし、記録が蓄積されるにつれ、観察対象は明確に以下の領域へと移行している。
・身体における微細な張力・緊張の知覚
・思考や注意がどのように発生し、どこへ向かうかの認知プロセスの観察
・「自分がやっている」という自己感覚（主観）の変容

**[USER MODEL]**
最新の記録において本人は、この一連の観察姿勢について、「絶対に間違えないこと（正しさ）」よりも「自分の状態を観察し、違ったときにどう修正するか（修正可能性）」を重視する『柔軟性』こそが健康であるという認識モデルを提示している（SRC_248）。

**[UNRESOLVED]**
当初、どのような具体的な問題意識からこれらの観察が開始されたかについて、一次資料上で唯一の明確な動機として断定できる記述は存在しない。

# Part II: 身体から始まった変化

**[SOURCE FACT]**
資料群では、身体の特定部位における物理的な感覚の変化が反復して記録されている。特に、頸椎から胸椎にかけての微細な調整や、腰・骨盤の配置に関する観察が多い。本人の記録によれば、「底の脱力」や「頭部と胸郭の相対角度が極端にならないこと」（SRC_066）が、身体上の重要な基準として記述されている。

**[USER MODEL]**
本人はこれらの身体状態を、「神経力学的なゼロ誤差基準」や「常時オート微調整」（SRC_026）といった独自の概念を用いて説明している。さらに最新のモデルでは、主観的な心地よさを『身体側の快』と『脳側の快』の2軸に分離し、脳側の体感を強めると身体からの内受容信号（痛みなど）が背景化し、意識上の重みが低下するというモデルを提示している（SRC_249）。

**[CROSS-SOURCE PATTERN]**
複数の記録において、「身体の張力が抜けた状態」が維持されるとともに、日常的な身体的・精神的疲労感が減少したことが報告されている。

# Part III: 認知・注意・思考の変化

**[SOURCE FACT]**
認知領域の記録において頻繁に記述されているのが、思考や注意のノイズが減少したという観察である。「反応は必要最低限で保たれる。過剰な揺れだけが落ちている状態」（SRC_072）といった記述が複数確認される。

**[USER MODEL]**
本人はこの認知的な変化を説明する際、「DMNの主従関係の反転」（SRC_073）や「RASの優先化の解除」として記述している。これらは体験を説明するために採用した神経科学的メタファーである。

**[CROSS-SOURCE PATTERN]**
資料を横断比較すると、「思考量（ノイズ）の低下」と「意識の明晰さの維持」が並立して記録されている。本人はこれを「無想だけど『思考停止』ではない」（SRC_073）と明記している。

# Part IV: 自己感覚の変化

**[SOURCE FACT]**
資料群において、「自分がやっている」といった主観的な自己感覚が希薄化していく過程が複数の記録に残されている。「自己イメージファイルをロードするようなものがなくなり、淡々と動いている感覚」（SRC_026）といった記述が存在する。

**[USER MODEL]**
本人は、この自己感覚の変容を表現するために「俺フィルター」や「自己パッケージ」といった概念を使用している。さらに最新の思考実験において、自己感の希薄化は「欠落」ではなく「自己を必須条件としていない（非依存）」という価値観の変化として説明されている。「無限の力や快楽」を得るためであっても、この「外界や自己に依存しない自由」を失う理由はないと定義されている（SRC_250）。

**[CROSS-SOURCE PATTERN]**
主観的な自己イメージの希薄化が記録された時期にも、日常的な判断や機能の停止は報告されておらず、複雑な社会機能の維持が並立して記録されている。

# Part V: 感情・欲求・快不快の変化

**[SOURCE FACT]**
感覚としての「快・不快」の存在と、それが持続的な「欲求・苦痛」へ接続されないという記録が併存している。本人は「快が持続的欲求へ育たない状態」（SRC_216）と記録している。

**[USER MODEL]**
本人は『やりたい（欲求）』と『やりたくない（拒絶）』の消失を、能力の欠如ではなく、『刺激に対する自動的な脳体感の生成がキャンセルされている状態』として説明している。この自動配分の弱さが、行動の自由度を上げる一方で『何をしたいか分からない』という代償を生んでいるとしている（SRC_249）。

**[CROSS-SOURCE PATTERN]**
記録を横断すると、「感覚入力（快・不快）」と「出力への要求（持続的欲求・回避欲求）」が明確に分離しているという非対称性が観察される。

# Part VI: 行動の成立と開始

**[CROSS-SOURCE PATTERN]**
既知・反復行動については自然に発生する一方、新規・足し算型タスクにおいては「意図して実行できない」という開始困難の記録が存在する。

**[USER MODEL]**
この非対称性について、本人は「自動的な欲求（脳体感）がキャンセルされているため、環境から自然な推進力を得られない」と説明している。そのため、大きな行動を起こす際には、身体と脳のリソース配分（内的状態）を「手動で両方しっかり作る」経路が必要になるとしている（SRC_249）。

**[UNRESOLVED]**
行動が発生した事実は記録されているが、日常行為における自動的な行動開始の物理的トリガーについては判断不能である。

# Part VII: 意識状態・PNSE・静寂

**[SOURCE FACT]**
「静寂」や「何もない」という感覚が頻繁に記録されている。これは虚無感とは区別されている。大量の知覚情報があるにもかかわらず、それにリアリティを感じる情動が伴わない状態（凪）が記述されている（SRC_251）。

**[USER MODEL]**
本人は、「世界がリアルだ」という主観的感覚を、情報そのものの属性ではなく「脳が後から付与する質感（テクスチャ）」と定義している。現在の状態は「非没入により情報量は多いが、リアリティの質感が付加されないため、覚醒体験のような圧倒的リアルではなく『凪』になる」と説明している（SRC_251）。

**[UNRESOLVED]**
本人の体験がPNSE等の概念が指し示す状態と同一であるかどうかは、資料群からは客観的に判断できない。

# Part VIII: 睡眠・疲労・覚醒

**[SOURCE FACT]**
「精神的疲労はほぼ消失」（SRC_216）と記録する一方で、「一過性の強い生理的眠気」（SRC_231）の存在を記述している。

**[USER MODEL]**
本人は、『睡眠時間の短さ』と『日中の眠気・疲労感の少なさ』を明確に区別し、後者が主観的に良好であっても、長期的な身体的負荷がゼロであるとは証明できないと明記している（SRC_248）。

**[CROSS-SOURCE PATTERN]**
強い「生理的眠気」が生じていると記録されているが、それが主観的な「苦痛」には変換されていない。

# Part IX: 社会生活と記録された活動

**[SOURCE FACT]**
内面的な「自己感の希薄化」や「リアリティ・テクスチャの消失」が記録されている同時期に、「会話」「運転」「仕事における判断」などの実生活の活動が記録されている。

**[CROSS-SOURCE PATTERN]**
情動的なリアリティ（脳感）が消失しても、重力や触覚などの「身体統合フィードバック」が維持されているため、解離や非現実感には陥らず、物理的な社会適応は正常に維持されている（SRC_251）。

# Part XI: 2026年8月：現在地点（中央と辺境）

直近の資料群（SRC_248〜251）に記録されている状態のスナップショットである。
本人は医学的エビデンス（中央）を否定しないが、標準が自分に合わない場合は、自身の体感をベースにした探索（辺境）を許容している。健康を「絶対に間違えない正しい方法に固執すること」ではなく、「違ったら修正すればいいという柔軟性（修正可能性）」と定義し直している。内部状態は「自動反応がキャンセルされた高い自由度」と「推進力の低下」のトレードオフの中にあり、自己を維持する必要性（執着）から離れたフラットな状態（凪）にある。
