# 主観の変化を記録する
身体・認知・自己感・欲求・行動・意識をめぐる一人称ケース・ドキュメント

**Version:** 1.0
**Date:** 2026年8月

---

## 本冊子の目的
本冊子は、一人称による長期的な観察記録を、FACT（観察事実） / USER MODEL（本人のモデル） / PATTERN（複数資料のパターン） / UNRESOLVED（未解決事項）の4層に分けて整理したケース・ドキュメントである。
本冊子は、単一の原因や理論によって体験を説明することを目的としない。
「観察された記述」「本人による解釈」「資料間のパターン」「未解決事項」を分離して保存する。

## 用語上の注意
本冊子に登場するDMN、RAS、予測処理等の神経科学的用語と、俺フィルター、自己パッケージ等の独自概念は、同一の認識論的地位を持たない。
本人が神経科学的用語を用いて自身の体験を説明している場合、それは原則として「本人が事象を説明するために採用したモデル（USER MODEL）」として扱う。
それらの記述は、実際の神経活動が測定・確認されたことを意味しない。

## この冊子の読み方
* **SOURCE FACT**: 資料に記録された事実・本人の報告。
* **USER MODEL**: 本人が体験を説明するために使用したモデル・比喩・仮説。
* **CROSS-SOURCE PATTERN**: 複数資料を比較した際に確認できる共起、前後関係、対照性、非対称性。
* **UNRESOLVED**: 資料から判断できない事項、または記述が不足している事項。

# Part I：この探究は何を追ってきたのか

### 1. 記録の出発点と観察対象の変遷
**[SOURCE FACT]**
本コーパスの初期記録群において、観察対象は「特定の問題解決」から「主観的体験の微細なモニタリング」へと推移していく過程が記録されている。
しかし、記録が蓄積されるにつれ、観察対象は明確に以下の領域へと移行している。
* 身体における微細な張力・緊張の知覚
* 思考や注意がどのように発生し、どこへ向かうかの認知プロセスの観察
* 「自分がやっている」という自己感覚（主観）の変容

本人はこの長期的な記録行動について、「自分自身に実際に起きてきた変化を、できるだけそのまま言語化しようとしている」（SRC_205）と記述しており、特定の理論的完成を目的としたものではないと明記している。

**[UNRESOLVED]**
当初、どのような具体的な問題意識からこれらの観察が開始されたかについて、一次資料上で唯一の明確な動機として断定できる記述は存在しない。

# Part II：身体から始まった変化

### 1. 姿勢と内部張力の観察事実
**[SOURCE FACT]**
資料群では、身体の特定部位における物理的な感覚の変化が反復して記録されている。
特に、頸椎から胸椎にかけての微細な調整や、腰・骨盤の配置に関する観察が多い。本人の記録によれば、「底の脱力」や「頭部と胸郭の相対角度が極端にならないこと」（SRC_066）が、身体上の重要な基準として記述されている。

### 2. 本人が使用したモデル
**[USER MODEL]**
本人はこれらの身体状態を、「神経力学的なゼロ誤差基準」や「常時オート微調整（脱りきみベース）」（SRC_026）といった独自の概念を用いて説明している。これは本人が自身の体感を整理するために用いたモデルである。

### 3. 疲労感の減少と身体感覚
**[CROSS-SOURCE PATTERN]**
複数の記録において、「身体の張力が抜けた状態」が維持されるとともに、日常的な身体的・精神的疲労感が減少したことが報告されている。
また、身体感覚が消失したのではなく、むしろ微細な反応を観測できている状態が記録されている。

**[UNRESOLVED]**
身体の緊張が低下したことと疲労感が減少したことは同時期に記録されているが、厳密な因果関係（どちらが発端か）については資料からは判断できない。

# Part III：認知・注意・思考の変化

### 1. 思考量の減少と明晰さの記録
**[SOURCE FACT]**
認知領域の記録において頻繁に記述されているのが、思考や注意のノイズが減少したという観察である。「反応は必要最低限で保たれる。過剰な揺れだけが落ちている状態」（SRC_072）といった記述が複数確認される。

### 2. 予測処理と注意に関するモデル
**[USER MODEL]**
本人はこの認知的な変化を説明する際、「DMNの主従関係の反転」（SRC_073）や「RASの優先化の解除」として記述している。これらは体験を説明するために採用した神経科学的メタファーである。

### 3. 横断パターンと非対称性
**[CROSS-SOURCE PATTERN]**
資料を横断比較すると、「思考量（ノイズ）の低下」と「意識の明晰さの維持」が並立して記録されている。
本人はこれを「無想だけど『思考停止』ではない」（SRC_073）と明記している。

**[UNRESOLVED]**
Part IIにおける「身体の張力の低下」と、Part IIIにおける「認知ノイズの低下」は並行して記録されているが、直接的な因果メカニズムは判断不能である。

# Part IV：自己感覚の変化

### 1. 「自分」という感覚の希薄化
**[SOURCE FACT]**
資料群において、「自分がやっている」といった主観的な自己感覚が希薄化していく過程が複数の記録に残されている。「自己イメージファイルをロードするようなものがなくなり、淡々と動いている感覚」（SRC_026）といった記述が存在する。

### 2. 本人が使用したモデル
**[USER MODEL]**
本人は、この自己感覚の変容を表現するために「俺フィルター」や「自己パッケージ」といった概念を使用している。自己感覚が完全に消滅したのではなく「必要な場面でのみ立ち上がる」（SRC_044）と記述している。

### 3. 横断パターンと未解決事項
**[CROSS-SOURCE PATTERN]**
複数の資料を比較すると、主観的な自己イメージの希薄化が記録された時期にも、日常的な判断や機能の停止は報告されておらず、複雑な社会機能の維持が並立して記録されている。

**[UNRESOLVED]**
自己感の低下と認知ノイズの減少は同時期に進行している記録が多いが、どちらが発端であるかは判断不能である。

# Part V：感情・欲求・快不快の変化

### 1. 快と欲求、不快と苦痛の分離
**[SOURCE FACT]**
感覚としての「快・不快」の存在と、それが持続的な「欲求・苦痛」へ接続されないという記録が併存している。本人は「快が持続的欲求へ育たない状態」（SRC_216）と記録している。

### 2. 本人が使用したモデル
**[USER MODEL]**
本人はこの状態を、「欲望駆動からの移行」と表現している。

### 3. 横断パターンと未解決事項
**[CROSS-SOURCE PATTERN]**
記録を横断すると、「感覚入力（快・不快）」と「出力への要求（持続的欲求・回避欲求）」が明確に分離しているという非対称性が観察される。

| 記録された現象 | 対照的に記録された現象 |
| --- | --- |
| 快感 | 持続的欲求の記述なし |
| 不快感 | 苦痛・回避欲求の記述なし |

**[UNRESOLVED]**
なぜ快感が欲求に接続されなくなったのか、直接的なメカニズムは判断不能である。

# Part VI：行動の成立と開始

### 1. 既知行動と新規タスクにおける開始の非対称性
**[CROSS-SOURCE PATTERN]**
既知・反復行動については、「条件が揃った結果、自然に発生している行為」（SRC_168）と成立事実が記録されている。一方で、新規・足し算型タスクにおいては、「意図して実行できない」（SRC_056）といった開始困難の記録が存在する。

| 記録された現象 | 対照的に記録された現象 |
| --- | --- |
| 既知・応答型タスク | 開始・維持が成立 |
| 新規・足し算型タスク | 開始・維持が困難 |

### 2. 「意思」に関する対立的記述
**[SOURCE FACT] / [USER MODEL]**
「意思で直接動く」（SRC_026）という記述と「意図して実行できない」（SRC_056）という記述が併存している。前者は日常行為、後者は新規タスクという状況の違いがある。

### 3. 行動開始トリガーの欠測
**[UNRESOLVED]**
行動が発生した事実は記録されているが、その開始過程についての主観的な記述は確認できない。行動を開始させる物理的・認知的なトリガーが何であったかについては判断不能である。

### 2. 眠気と苦痛の非対称性
**[CROSS-SOURCE PATTERN]**
本人は強い「生理的眠気」が生じていると記録しているが、それが同時に主観的な「睡眠不足の警告としての苦痛」には変換されていないと記述している。

| 記録された現象 | 対照的に記録された現象 |

**[UNRESOLVED]**
生理的眠気への拘束力低下が、神経系の沈静化とどのような因果関係を持っているかは判断不能である。
