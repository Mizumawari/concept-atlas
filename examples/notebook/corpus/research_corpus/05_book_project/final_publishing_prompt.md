# 最終成果物生成指示

あなたは本フェーズにおいて、**研究者・分析者・編集者ではなく、組版および成果物生成オペレーターとしてのみ動作する。**
目的は、すでに完成・固定された第3層「完全版研究冊子」を、**閲覧・保存・共有可能な冊子形式の成果物**として出力することである。

## 1. 使用する原稿
以下を唯一の本文ソースとする。
* 第3層 Phase 4-A〜4-Dで固定された本文
* Part I〜Part XII
* 既に固定された巻頭の「用語上の注意」「本冊子の目的」
* 各PartのSOURCE FACT / USER MODEL / CROSS-SOURCE PATTERN / UNRESOLVED
* 最終的に固定された注意書き・監査ルール

**本文の再分析・再解釈・再構成は禁止。**

---

# 2. 成果物
以下の2種類を生成する。
### A. DOCX
ファイル名：case_document_v1.0_master.docx（今後更新可能な**マスター版**）
### B. PDF
ファイル名：case_document_v1.0.pdf（Version 1.0時点の**固定版・閲覧用アーカイブ**）

---

# 3. 冊子としての基本仕様
目的は「論文風に見せること」ではなく、長期間にわたる一人称記録を後から読み返せるケース・ドキュメントとして整理保存することである。
* A4縦、白背景、可読性優先、十分な余白、読みやすい文字サイズ
* 見出し階層の明確化、Partごとの明確な区切り
* ページ番号、簡潔なヘッダー／フッター
* 過度な装飾・派手なカラーリングの禁止

---

# 4. 4つの情報レイヤーを視覚的に区別する
SOURCE FACT / USER MODEL / CROSS-SOURCE PATTERN / UNRESOLVED を視覚的に識別できるようにする。ただし、視覚的な区別によって内容の意味を変更してはいけない。

---

# 5. 特に重要な禁止事項
* 因果関係、仮説、科学的説明、医学的評価、心理学的診断の追加
* 「悟り」「覚醒」「PNSE」等への分類
* USER MODELを科学的事実として扱う
* 「記述がない」を「存在しない」に変更する
* 「本人がそう記述した」を編集者の事実認定に変更する
* 評価語の追加、Part Xの時系列を因果関係として表現する
* 本文の短縮や、読みやすさを理由とした意味の言い換え
**組版上の修正と本文上の修正を完全に分離すること。**

---

# 6. 冒頭に入れる構造
1. 表紙 2. 冊子タイトル 3. Version情報 4. 本冊子の目的 5. 用語上の注意 6. 本冊子の読み方 7. 目次 8. Part I〜XII
※「本冊子の読み方」では4層を区別して読む必要があることだけを説明する。新しい理論的説明は追加しない。

---

# 7. 各Partの組版
各Partは原則として新しいページから開始する。4層が存在する場合は視覚的に識別できるようにするが、原稿に存在しないレイヤーを新たに作らない。

---

# 8. SOURCE ID
SRC_026 などのSOURCE IDは削除せず原文どおり保持する。読者が本文と元資料の対応関係を追跡できることが重要。

---

# 9. Part XII
Part XII「まだ分からないこと」は冊子の重要な構成要素として扱う。既存原稿に記載されたUNRESOLVEDをそのまま収録し、空白を説明で埋めない。

---

# 10. 最終監査
**【内容監査】** 全Part・全SOURCE ID・UNRESOLVEDが存在するか。因果関係や解釈が混入していないか。
**【組版監査】** 文字化けがないか。見出し階層、ページ番号、目次の対応が取れているか。不自然な分断がないか。PDFとDOCXが一致しているか。

---

# 11. 重要な最終ルール
このフェーズでは、**「もっと良い文章にする」ことを禁止する。**文章、理論、説明、結論を改善しない。
やることはただ一つ、
> **固定された研究冊子を、意味を変えずに、人間が読める一冊の成果物へ変換すること。**

以上。
