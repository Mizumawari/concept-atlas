# Action Initiation Corpus (行動開始コーパス)

本ファイルは、コーパス内における「行動」および「その開始プロセス」に関する記述を、推論・解釈（AI仮説）を完全に排除した状態で記録するための基礎データフォーマットである。
各事例について、原文に「記述があるか／ないか／否定されているか」のみを厳格に分類する。

## データフォーマット

| 項目 | 記録内容（記述あり／否定／記述なし・不明） |
| :--- | :--- |
| **SRC** | SRC_XXX |
| **行動** | 何をしたか |
| **S0** | 行動について言及されただけ |
| **S1 (選択)** | やろうと思った／選択した |
| **S2 (操作)** | 具体的操作に入った |
| **S3 (発生)** | 行動が実際に発生した |
| **S4 (継続)** | 行動が継続した |
| **S5 (完了)** | 行動が終了／完了した |
| **自己イメージ** | あり／なし／不明 |
| **欲求** | あり／なし／不明 |
| **意図** | あり／なし／不明 |
| **外部条件** | 記述あり／なし |
| **開始トリガー** | 記述あり（内容）／なし |
| **原文** | 原文からの引用 |
| **解釈** | （※記載しない） |
