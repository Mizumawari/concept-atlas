強迫性障害・注意制御・PNSEに関する統合的整理
― 未完了感・RAS誤作動・自然消退の過程 ―
1. 個人的前提・経過整理
- 元々、軽度〜中等度の強迫性傾向があった
- 主症状は確認行動
- 「ちゃんとやったか分からない」という感触が中心
- ただし、生活を著しく阻害するレベルではなかった
- 現在は
- 強迫行為・不安・思考のループはほぼ消失
- 症状は 段階的・自然に弱まった
- 一部特定条件下でのみ、感触の輪郭が残存
- 現状では
- 問題化していない
- 行動に駆動されない
- 直感・集中を妨げない
- 生活・判断への影響なし
2. 強迫性障害の基本構造（再定義）
2.1 一般的誤解
- 強迫性障害は「考えすぎ」「性格」「不合理な思考」の問題とされがち
- 実際には、本人は不合理性を理解していることが多い
2.2 実態
- 中核は
思考内容ではなく、感触（未完了感・不確実感）
- 強迫観念は
→ 感触に対する後付け解釈
3. 「やったかどうか分からない感触」の正体
3.1 記憶の問題ではない
- 記憶がある場合でも感触は生じる
- 行為の事実を思い出せても確信が出ない
3.2 完了シグナル障害
- 通常：
- 行為 → 完了 → 確信の感触 → 注意解除
- 強迫性：
- 行為 → 完了
- 確信の感触が生成されない
- 結果として
- 「やってないかもしれない」という思考が生成される
4. RAS（網様体賦活系）寄り誤作動仮説
4.1 RASの役割
- 注意・覚醒のゲート
- 「重要か？」
- 「注意を向け続けるべきか？」
- 「終わったか？」
を身体寄りの信号として判断
4.2 強迫性との関係
- 「要注意」フラグが切れない
- 危険がなくても注意解除が起きない
- 思考よりも注意系の過剰作動
5. 強迫行為が生じる神経的ループ
- 未完了感が残る
→ 注意が解除されない
→ 不快
→ 解除のための行動（確認）
- 確認行動により一時的安心
→ RASが
「この信号は重要」「確認で解決する」
と学習
→ 強迫性ループが固定化
6. 症状が段階的に消えていった理由
6.1 一般的改善ルートとの違い
- 意志や説得で消えたわけではない
- 思考修正が主因ではない
6.2 実際に起きていたこと
- 感触は出る
- しかし行動しない
- 何も起きない
この経験が長期間継続
→ RASが再学習
「この信号は重要ではない」
→ 発火頻度・強度が自然低下
7. PNSE（恒常的非象徴的体験）との接続
7.1 PNSEの最小定義
- 内的独白がほぼ生じない
- 意味づけ・評価・自己物語生成が弱い
- 「今起きていること」がそのまま知覚される状態が恒常化
7.2 注意処理の変化
通常：
1. 信号発生
2. 意味づけ
3. 評価（重要性判断）
4. 行動・思考へ接続
PNSE的注意状態：
- ②③④が大幅に弱まる
→ 感触は立ち上がるが
→ 意味を持たず
→ 行動に結びつかない
8. 強迫性が自然に背景化した理由（PNSE視点）
- 未完了感が出ても
- 思考展開なし
- 行動なし
- 自己評価なし
- 神経系は
「反応が起きない信号」を重要視しなくなる
→ 感触が使われなくなる
これが
「いつの間にか消えていた」
という体感につながる
9. 現在残っている「輪郭的感触」の位置づけ
9.1 性質
- 不安を伴わない
- 行動を駆動しない
- 思考と結びつかない
- 直感・集中を妨げない
9.2 解釈
- 症状ではなく
神経回路の痕跡
- 注意解像度が高いため、微細な信号を観測できている状態
10. 「細かいところが気になる感触」の再定義
- 強迫性ではなく注意感度
- 未完了・ズレ・例外を検知する能力の名残
- 「気づくが採用しない」
- システムを起動しない
11. 直感・集中との関係
- 直感・集中は
- 注意が一点に流れ
- 自己チェックが介在しない
状態で成立
- 現在：
- 割り込みなし
- 横槍なし
- 判断が鈍らない
→ 強迫性が構造的に再起動できない状態
12. 「行動を止めれば消える」という見立て
- 強迫性は
感触 → 行動 → 安心
のループで維持
- 現在は
感触 → 行動しない → 無反応
→ RASが信号価値を下げ
→ 自然減衰
13. 現在の総合的位置づけ
- 強迫性障害としては事実上解体済み
- 残存しているのは
- 感触の名残
- 神経系の地形
- 消えてもよいし、消えなくても問題ない
- 症状ではなく特性
- 実生活上の問題は成立しない
14. 結論
- 強迫性の核心は
思考ではなく注意・覚醒信号
- PNSE的注意状態では
信号が意味・自己物語に接続されない
- 行動・安心・評価が起きないため
神経系が再調整される
- 結果として
徐々に・自然に・背景化した
- 残る輪郭は異常ではなく
感度の名残
補足的結語
強迫性が「消えた」というより、
注意の座標系が変わった
と表現する方が正確。
未完了感は、
かつては行動を生む信号だった。
今はただ、
通過していく感触にすぎない。
