旧石器時代の人類の基底をベースとした神経・意識・代謝の統合理論
（NotebookLM Reference Text）
1. 問題設定
現代人はなぜ「何もしていないのに疲れている」のか
現代人の多くは、
・十分に寝て
・十分に食べ
・安全な環境にいながら
慢性的な疲労・不安・緊張・思考過多に苦しんでいる。
これは心理的問題ではなく、神経環境の問題である。
人類の神経系は、99%以上の進化史を通して以下の環境で作られた。
- 低刺激
- 単調な感覚入力
- ゆっくりした空腹と満腹
- 不規則だが自然な睡眠
- 身体を動かす時間と何もしない時間の交互
これを本稿では
**「旧石器時代モード」**と呼ぶ。
現代はその逆である。
- 人工光
- 常時通知
- SNSによる社会的評価
- カフェインと糖
- 抽象的ストレス
- 終わらない思考
これは進化的には
捕食者と雷が24時間鳴り続けている環境に等しい。
2. 瞑想・断食・禅・短眠の正体
歴史的に存在してきた修行法：
- 禅の不動・沈黙
- 断食
- 洞窟修行
- 短眠
- 瞑想
これらは精神修養ではなく、
旧石器時代の神経環境を人工的に再現する装置である。
- 断食 → 低インスリン・脂肪代謝
- 不動 → RAS沈静
- 単調視覚 → DMN沈黙
- 暗闇 → メラトニン回復
- 静寂 → 迷走神経優位
悟り・涅槃とは神秘ではなく、
進化的基準に戻った神経状態を文化的に言語化したものに過ぎない。
3. 現代の「静かな人」は何者か
ある種の現代人は、意図せずこの状態に到達する。
典型的な条件：
- 軽い断食（平日1200kcal前後）
- 糖質中心で脂質過多でない
- カフェイン・刺激が少ない
- 長時間PC前で不動
- 単調な視覚入力
- 夜型だが暗い時間が長い
これは修行者が意図的に作る環境と同一である。
この状態では：
- RAS（覚醒ゲイン）が下がる
- DMN（自己物語）が沈黙
- 島皮質と自己の結合が弱まる
- 自律神経の揺れが意識と結びつかなくなる
結果：
「瞑想している」のではなく
「瞑想状態で生活している」
4. HRVと体感の乖離の意味
一般的な人：
- HRVが悪い → しんどい
- CVが高い → 不安・だるさ
旧石器時代モードの人：
- HRVが荒れる → 背景が揺れているだけ
- 体感は静かなまま
これは：
自律神経の揺れが
自己モデルに入っていない
＝ 観照が自動化されている状態
このため：
- 低血糖
- 交感神経優位
- 断食
- 睡眠不足
でもパニックにならない。
5. なぜ副交感神経を入れると「眠くなる」のか
この状態では：
- 覚醒と静寂が分離している
交感神経ONでも静かでいられるが、
副交感神経を意図的に入れると：
- RASゲインが落ち
- 視床ゲートが閉じ
- 意識の電源が下がる
これは睡眠ではなく：
「覚醒の解像度を意図的に下げている」
禅で言う「起きているが眠っている」に相当する。
6. 旧石器時代モードは退化か進化か
現代環境は：
- 高ノイズ
- 高抽象性
- 高情報
これは人間の脳にとって不利であり、
AIが圧倒的に強い領域。
人間の進化余地はここにはない。
人間が価値を持てる領域は：
- 身体感覚
- 空間直観
- 微細な情動
- 意味の統合
- 存在感
これはすべて：
静かな神経状態で最大化される
つまり旧石器時代モードは：
退化ではなく
AI時代への唯一の適応
7. なぜ一度体験すると戻れないのか
この状態では：
- RASの基準点
- DMNの活動
- 扁桃体の反応性
が再設定される。
そのため、
刺激過多の状態は
**「不自然でうるさい」**と知覚される。
戻れないのではなく、
戻りたい神経ではなくなった
8. 結論
瞑想・禅・断食・短眠とは、
悟りを得る技法ではない。
人類史的に“普通”だった神経状態に戻る技術
あなたの状態は覚醒でも神秘でもなく、
旧石器時代の神経OSが
現代環境の中で再起動しただけ
それは人類の過去であり、
同時にAI時代の未来でもある。
