# ドーパミン・情動・巡航状態
## ― 刺激モデルから状態モデルへの脳構造考察 ―
## 概要
現代社会では、人間の幸福やモチベーションはしばしば
**ドーパミン（刺激・興奮）モデル**によって説明される。
しかしこのモデルは構造的に持続性が低く、長期的には
* 刺激の増幅
* 快楽耐性
* 行動のエスカレーション
などを引き起こしやすい。
さらに刺激モデルが減衰すると、人間はしばしば
**情動・意味・正義**を基盤とする行動モデルへ移行する。
この情動モデルは社会的結束を生む一方で
* 宗教対立
* イデオロギー闘争
* 戦争
などの集団的暴力の基盤にもなりやすい。
本考察では、人間の行動・幸福の構造を
**三つの層（刺激・情動・状態）**として整理する。
---

# 1. 刺激層（ドーパミンモデル）
最も表層にある行動駆動システム。
構造
```
刺激
↓
ドーパミン放出
↓
興奮・快感
↓
減衰
↓
次の刺激探索
```
神経系
* VTA（腹側被蓋野）
* 側坐核
* 前頭前野
特徴
* 新奇性依存
* 快楽イベント中心
* 耐性が発生する
結果
```
刺激 ↑
↓
慣れ
↓
刺激エスカレーション
```
例
* SNS
* ギャンブル
* 消費
* 成功依存
* 承認依存
このシステムは進化的には
**探索行動（資源探索）**のための回路であり、
長期幸福システムとしては設計されていない。
---

# 2. 情動層（意味・帰属モデル）
刺激モデルが弱まると、多くの人は
**意味・正義・帰属**による行動に移行する。
構造
```
意味
↓
情動
↓
正義
↓
行動
```
神経系
* 扁桃体
* 前帯状皮質
* 島皮質
* オキシトシン系
特徴
* 強い動機
* 集団性
* 物語形成
この層は
```
内集団
vs
外集団
```
を生みやすい。
そのため歴史的に
* 宗教戦争
* 民族紛争
* ナショナリズム
* 革命粛清
などの社会的悲劇の基盤となる。
重要な特徴として
```
攻撃
↓
正義
```
という認識が成立する。
このためこの層は
**個人快楽よりもはるかに強い行動エネルギー**を生む。
---

# 3. 状態層（巡航状態）
さらに深い層として、
刺激・情動の両方に依存しない
**状態ベースの行動モード**が存在する可能性がある。
神経的特徴
* DMN（自己物語ネットワーク）の低活動
* サリエンス信号の低振幅
* 覚醒の安定化
結果として
* 刺激への反応低下
* 情動の短時間化
* 注意の安定
などが起こる。
特徴
* 退屈が発生しない
* 集中が切れる感覚がない
* 行動は自然発生する
* 強い欲求が少ない
構造
```
状態
↓
行動
```
通常のモデル
```
欲求
↓
行動
```
とは異なる。
---

# 4. 痛みと苦悩の分離
この状態では
**身体信号と心理的苦悩が分離する傾向**がある。
痛みは2種類に分けられる。
### 感覚的痛み
```
強度
場所
刺激
```
神経系
* 体性感覚野
* 視床
### 苦悩的痛み
```
嫌悪
恐怖
意味づけ
```
神経系
* 前帯状皮質
* 扁桃体
* DMN
通常は
```
痛み
↓
意味
↓
苦悩
```
になるが、
状態層では
```
痛み
↓
身体反応
```
で止まることがある。
その結果
**苦はあるが苦悩は増幅されない。**
---

# 5. 欲求の変化
人間の欲求は主に三種類ある。
### ドーパミン欲求
```
刺激
↓
欲求
```
### 情動欲求
```
意味
↓
信念
↓
行動
```
### 生理欲求
```
空腹
眠気
痛み
```
状態層では
* ドーパミン欲求
* 情動欲求
が弱まり、
残るのは
```
身体信号
```
のみとなる。
---

# 6. 行動の構造
多くの人は
```
意味
↓
モチベーション
↓
行動
```
で動く。
しかし状態層では
```
状況理解
↓
適切行動
```
という形になる。
つまり
```
意味
```
ではなく
```
適切性
```
が行動基準となる。
---

# 7. 結論
人間の行動・幸福の構造は
大きく三層に整理できる。
```
刺激層（ドーパミン）
↓
情動層（意味・正義）
↓
状態層（巡航状態）
```
刺激層は
* 快楽依存
* 耐性
を持つ。
情動層は
* 強い行動力
* 集団暴走
の可能性を持つ。
状態層は
* 刺激依存が少ない
* 行動は自然発生する
* 苦はあるが苦悩は少ない
という特徴を持つ。
