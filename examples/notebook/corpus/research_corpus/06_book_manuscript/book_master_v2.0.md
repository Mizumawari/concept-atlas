# 序章：この記録について

「覚醒」や「悟り」、あるいは「マインドフルネス」と呼ばれるような状態について語られるとき、そこにはしばしば、精神的な修行や劇的な価値観の変化という物語が付随する。
しかし、本書が提示するのはそのような完成された物語ではない。ここにあるのは、ある一個人の身体と認知に起きた変化を、長期間にわたってモニタリングした一次記録（ケース・ドキュメント）である。

初期の記録群を遡ると、観察の対象はもともと「特定の問題解決」に向いていた形跡がある。しかし記録が蓄積されるにつれ、観察の対象は明確に移行していく。身体における微細な張力や緊張の知覚。思考や注意がどのように発生し、どこへ向かうかのプロセス。そして、「自分がやっている」という自己感覚（主観）そのものの変容へと、記述の焦点が移っていくのである。

本書は、単一の理論や原因によってこれらの体験を説明することを目的としていない。「何が起きたのか（事実）」と、「本人がそれをどう説明しようとしたか（解釈）」を厳密に分け、非対称な現象を無理に統合することなく、そのままの形で読者に提示する。
これは、心と身体のシステムを観察し続けた、n=1（サンプル数1）の解体新書である。

# 第一部：身体

初期の記録において、最も頻繁に記述されているのは、極めて物理的で微細な「身体の調整」に関する観察である。

記録には、頸椎から胸椎にかけての微細な骨格の配置や、腰や骨盤の角度に関する言及が繰り返し現れる。たとえば、身体の底にある不要な「りきみ（張力）」をいかに知覚するか。あるいは、「頭部と胸郭の相対角度が極端にならないこと」をいかに維持するかといった、具体的な身体操作の記述が残されている。
当時の本人は、これらの身体状態を表現するために「神経力学的なゼロ誤差基準」という言葉を用いている。自身の身体内にある物理的な緊張を探り当て、それをゼロに近づけていくこと。そして、その状態を維持することを、本人は「常時オート微調整」と呼んでいた。
それは思想的な探求というより、純粋で執拗な身体へのモニタリングの記録である。

この「常時オート微調整」に関する記述が記録に定着していくのと同じ時期に、記録上にはもう一つの明らかな変化が現れ始める。
疲労感の消失についての記述である。
複数の記録において、身体の張力が抜けた状態が維持されることと並行して、「日常的な身体的・精神的疲労感が減少した」という本人の報告が残されている。

さらに、これらの身体的な観察記録が蓄積されていくにつれ、記録の対象は身体の物理的な領域だけにとどまらなくなっていく。
その後の記録では、身体の張力と並行するように、思考や注意といった「認知の領域」に何が起きているのかについての記述が広がり始めるのである。

# 第二部：ノイズ

身体に対するモニタリングの記録が続くのと同じ時期の資料に、別の領域への言及が現れ始める。思考や注意といった「認知」の領域についての記述である。

この時期の記録には、思考の量的な低下についての報告が頻繁に見られる。「反応は必要最低限で保たれる。過剰な揺れだけが落ちている状態」（SRC_072）という記述が存在する。
本人は当時の記録の中で、この認知的な変化を説明するために、「DMN（デフォルト・モード・ネットワーク）の主従関係の反転」や「RAS（網様体賦活系）の優先化の解除」といった神経科学的な用語を用いている。これらは、本人が自身の内面的な変化を捉えようとして採用したモデルである。

一方で、別の記録では、思考量が低下している状況において「意識の明晰さ」が維持されていることが記述されている。本人はこの状態を「無想だけど『思考停止』ではない」（SRC_073）という言葉で記録している。
思考のノイズが低下しているという記録と、意識の明晰さが保たれているという記録。一見すると連動しない二つの状態が、同時期に並立して記録されているのである。

これらの認知領域の変化に関する記録と、第一部で触れた「身体の微細な調整」に関する記録との間に、どのような関連性があるのかは、資料の記述からは判断できない。

# 第三部：自己

認知についての記述が増えていく一方で、別の記録では「自分がやっている」という感覚そのものが扱われ始める。

資料群の中には、「自己イメージファイルをロードするようなものがなくなり、淡々と動いている感覚」（SRC_026）といった記述が存在する。本人はこの時期、自身の状態を表現するために「俺フィルター」や「自己パッケージ」といった独自の言葉を使用している。何かを見たり行ったりする際に介在していた自己に対する認識が、希薄になっていることを示す記録である。

これと並行して、同じ時期の資料には、仕事における複雑な判断が行われた記録や、他者との会話が成立している記録が残されている。
「自分がこれをやっている」という感覚が薄れているという報告と、日常的な会話や業務上の判断が継続して実行されているという事実が、並んで記録されているのである。

本人が自己対話や自己イメージを介したものとして記述していない場面において、仕事上の判断や会話がどのように生成されているのか。そのプロセスについては主観の側に記述がなく、資料から特定することはできない。

# 第四部：欲求

「自分がやっている」という感覚についての記述が変化していく同時期の記録には、内面的な「欲求」や「感情」に関する別の観察が残されている。

この時期の資料には、食事を通した味覚の知覚や、身体的な不快感について、それが確かに存在しているという記述が存在する。「美味しい」という感覚や、「不快である」という感覚そのものは、記録上失われていない。
しかし、それらの知覚に関する詳細な記録と並んで、ある特徴的な報告が繰り返し現れる。それは、知覚された快や不快が「もっと欲しい」「明日も食べたい」という持続的な欲求、あるいは「避けたい」という持続的な苦痛へと接続しないという、本人の明示的な記述である（SRC_216）。

快や不快は知覚されている。しかし、持続的な欲求や苦痛としては記録されていない。
二つの異なる状態が、同じ時期の資料に並立しているのである。

後年の記録（2026年）において、本人はこの状態を振り返り、「自動的な脳体感の生成がキャンセルされている状態」（SRC_249）という独自のモデルを用いて説明を試みている。しかし、当時の記録の時点において残されているのは、あくまで「感覚は入力されているが、欲求としては出力されていない」という事実の描写のみである。

快・不快の知覚に関する記述と、持続的な欲求・苦痛に関する記述の間に、どのような関係があるのかは、当時の資料からは判断できない。

# 第五部：行動

欲求についての記述が変化していく時期の資料には、実際の「行動」についても別の特徴的な記述が現れている。

資料には、日常的な行動や仕事、あるいは既知のタスクが滞りなく実行されている記録が継続して残されている。しかし一方で、新規のタスクや「足し算型」の行動については、「意図して実行できない」という本人の明示的な記録が存在する。
また、日常の行動が実行されている事実が記録されているにもかかわらず、その行動を開始するにあたって「やろうと思った」あるいは「決断した」といった、行動開始過程の主観的な記述が確認できない。

本人は当時の記録において、この日常行動が成立する仕組みを「必要性駆動」という言葉を用いて説明している。これは、行動の発生を説明するために本人が採用したモデルである。
また、後年の記録（2026年）では、大きな行動を起こすプロセスについて「身体と脳の手動リソース配分」を行っているという新たな解釈が追加されている（SRC_249）。

既知の行動が成立しているという記録と、新規タスクでの開始困難という記録。
行動が成立しているという事実と、行動開始過程の主観的記述が不在であるという事実。
これらの記録は、同じ時期の資料内にそれぞれ並んで配置されている。

日常行為において、行動開始に関与した具体的な条件やプロセスが何であったのかは、資料の記述からは判断不能である。また、第四部に記録された「欲求」に関する記述と、この「行動」に関する記述が、どのような関係にあるかも特定できない。

# 終章：まだ分からないこと

この記録（コーパス）には、身体についての記述がある。認知についての記述がある。自己についての記述がある。欲求、行動、意識、睡眠についての記述も残されている。

それぞれの領域について、本人によって構築された説明モデルも並行して記録されている。しかし、本人による説明と、資料から客観的に確認できる事実は同じものではない。
また、記録されているそれぞれの領域の記述を、一つの機序によって結びつけるだけの資料も、現在のコーパスには存在しない。

したがって、この記録から確認できるのは、ここまでである。
